# Contributing to ContractSutra AI

Author: Vatsal Shah. Read README, compatibility policy, security boundaries and code of conduct. Keep contributions small, add regression fixtures for every new semantic rule, run `npm test` and `npm run lint`, and provide exact evidence in the PR. No production API keys or customer traffic in fixtures. For protocol adapters, cite a normative standard reference and prove actual integration in a scoped test before marking done. Human maintainers approve releases.
