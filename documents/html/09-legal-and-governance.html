Legal and governance

This page is a plain-language summary for transparency. It is not legal advice; consult counsel for your situation.

License#

Apache License 2.0 (LICENSE). You may use, modify and distribute the software, including commercially, subject to the license terms (attribution, notice of changes, patent grant and termination clause). Copyright 2026 Vatsal Shah. See NOTICE.

Warranty and liability#

Provided as is, without warranty of any kind (Apache-2.0 sections 7 and 8). Output is engineering evidence to support a human decision. It does not certify that an API is safe to release, compatible with any particular client, or compliant with any regulation or standard.

Data protection#

The tool is offline. It does not collect, transmit or store personal data and has no telemetry. Because it runs on your machine, you remain the data controller for any content in the specs you analyze. No data-processing agreement is needed for the tool itself. If you share reports, remember pointers and field names may reveal internal design.

Third-party code and marks#

No third-party runtime code is bundled. OpenAPI is a mark of the Linux Foundation / OpenAPI Initiative, SARIF is an OASIS standard, GitHub, npm, Claude, Cursor, Codex, Gemini, Copilot, Windsurf, Cline, Roo and Continue belong to their owners. This project is not affiliated with or endorsed by any of them. Mentions of IDE hosts mean the project ships instruction files for them; native activation is unverified.

Claims policy#

The project avoids the claims "100% secure", "fully compatible", "production ready", "consumer verified", "certified" and "audited by industry experts" because none is supported by evidence. Every capability in the documentation is marked implemented, partial, planned or not run.

Governance#

Single maintainer today (Vatsal Shah). Changes go through pull requests with CI. Security reports follow SECURITY.md. Contribution rules are in CONTRIBUTING.md; conduct in CODE_OF_CONDUCT.md; decision records in docs/ADR-*.md. Contributions are accepted under Apache-2.0.

Citation#

See CITATION.cff.

Responsible use#

Do not use the tool or its agent packs to probe systems you do not own or have permission to test. The tool itself performs no network access.
