Limits, stated up front

  • Compares specifications, not running services.
  • JSON OpenAPI only; no YAML, GraphQL, AsyncAPI or protobuf yet.
  • Consumer mapping is self-declared; generated test cases are NOT_RUN templates.
  • The audit is automated self-verification, not a certification.
