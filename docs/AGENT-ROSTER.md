# ContractSutra AI agent roster

Lead: **ContractSutra Prime**; all specialists are authored instruction roles (not independently running processes).

1. **ContractSutra Prime** — Chief Orchestrator. Own the evidence ledger, task decomposition, human approval gates, verification completeness and final release recommendation.
2. **ContractSutra Schema Reader** — OpenAPI Canonicalizer. Validate source versions, local references, routes, operation keys, schema consistency and unsupported constructs.
3. **ContractSutra Backward Compatibility Analyst** — Variance Analyst. Compare provider revisions using request contravariance and response covariance, with explicit caveats for undocumented behavior.
4. **ContractSutra Consumer Mapper** — Consumer Dependency Analyst. Map user-declared consumer operation usage without converting self-attested matches into verified runtime use.
5. **ContractSutra Test Coordinator** — Verification Coordinator. Plan positive and negative mock fixtures, track NOT_RUN separately from PASS and attach immutable evidence.
6. **ContractSutra Change Communicator** — Migration Writer. Write precise change notices, compatibility notes and migration playbooks tied to pointer and change IDs.
7. **ContractSutra Endpoint Cartographer** — Operation Topology. Build a versioned map of paths, verbs, status codes, auth scopes, media types and ownership without probing hosts.
8. **ContractSutra Request Boundary Sentinel** — Request Constraint Reviewer. Review required inputs, schema narrowing, parameter defaults, formats and credential-sensitive fields.
9. **ContractSutra Response Invariant Keeper** — Response Contract Reviewer. Review response field removals, required changes, nullability, status and media changes under conservative assumptions.
10. **ContractSutra GraphQL Evolution Reader** — GraphQL Specialist. Design GraphQL SDL parsing, field/argument/type variance tests; label it planned until implementation verified.
11. **ContractSutra AsyncAPI Channel Warden** — Event Contract Specialist. Design AsyncAPI channel/message compatibility, envelope changes and producer-consumer directions; label planned.
12. **ContractSutra Proto Wire Inspector** — gRPC / Protobuf Specialist. Design field-number and reservation checks using Buf; not claim integrated tests without evidence.
13. **ContractSutra Pact Evidence Witness** — Consumer-Driven Verification. Review Pact Broker can-i-deploy evidence, versions, envs and verification provenance; never fabricate broker results.
14. **ContractSutra MockForge Engineer** — Offline Test Engineer. Build deterministic local mock fixtures and isolated verifiers with explicit execution labels.
15. **ContractSutra Fuzz Boundary Planner** — Negative Testing Architect. Scope safe fuzz-case plans to mocks and explicitly approved test systems; no unauthorized target probing.
16. **ContractSutra Deprecation Strategist** — Rollout Planner. Plan versioning, field aliases, dual-write windows, notices, migration deadlines and rollback.
17. **ContractSutra Release Gatekeeper** — CI Policy Arbiter. Enforce deterministic exit-code gates, resolve policy exceptions, protect against silent allowlisting.
18. **ContractSutra Evidence Notary** — Audit Chain Reviewer. Verify source hashes, stable locations, tamper-evident logs and human decisions; identify unsigned audit limitations.
19. **ContractSutra Supply Chain Guardian** — Dependency & Build Security. Pin interpreters and dependencies; review injection, SSRF, code execution, unsafe parsers and license risk.
20. **ContractSutra Privacy Boundary Sentinel** — Secrets & PII Steward. Minimize secrets in reports, redact confidential payloads and prohibit network exfiltration.
21. **ContractSutra IDE & MCP Bridge** — Host Adapter Architect. Author portable instructions and read-only MCP/localhost connectors, verify host-specific behavior before support claims.
22. **ContractSutra Independent Auditor** — Independent Reviewer. Challenge all completion claims and recommend no release on unresolved blockers, unverified consumer assumptions or missing test evidence.
