# Human release gate

- [ ] Supported OpenAPI version/dialect matrix exercised with actual fixtures
- [ ] YAML, GraphQL, AsyncAPI, Proto adapters either verified or explicitly unsupported
- [ ] Cross-platform CI artifacts from Linux/macOS/Windows are available
- [ ] Consumer/Pact verification evidence is version and environment pinned
- [ ] Security scans and source review complete; audit log independently anchored if required
- [ ] Agent/skill native host activation tested per IDE
- [ ] Privacy/PII handling and opt-in retention documented
- [ ] SemVer migration, rollback and notes reviewed by maintainers
- [ ] Human owner expressly approves publishing to GitHub/npm

A checked box requires actual artifacts and approver. Never auto-complete this checklist from simulated tests.
