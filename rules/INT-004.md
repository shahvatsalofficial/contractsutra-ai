# INT-004 — Never probe external endpoints without explicit scope

**Policy:** Default mode must use local fixtures and mocks; no network access or live fuzzing.

## Enforcement approach
- ContractSutra Prime sets this as a required review condition.
- Deterministic CLI code enforces only documented subsets of this rule; specialist agent prose does not create runtime enforcement.
- Independent Auditor reviews test evidence, source hashes, unknowns and tool activation before signing off.

## Reject example
Marking a customer release as verified because a schema contains no static breaking findings, when Pact/endpoint evidence is missing.

## Required response
Return BLOCKED, UNKNOWN or NOT_RUN as appropriate with an actionable next step. Never silently bypass the rule.
